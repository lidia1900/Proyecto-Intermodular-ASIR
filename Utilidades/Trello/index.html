    Trello

    1. Introducción

    Trello es una herramienta de gestión de proyectos que permite organizar el trabajo de forma visual mediante tableros, listas y tarjetas.

    vamos a aprender su funcionamiento mediante un pequeño reto.

    2. Actividad: Organizamos un viaje de fin de curso

    Situación

    Sois un grupo de amigos y queréis organizar un viaje de fin de curso de 4 días.

    Tenéis que organizaros para decidir el destino, buscar transporte y alojamiento, calcular el presupuesto y preparar las actividades.

    Para coordinar todo el trabajo vais a utilizar Trello.

    !!! Objetivo !!! Descubrir por vosotros mismos cómo utilizar Trello para organizar un proyecto en equipo.

    2.1. Crear el espacio de trabajo

    Un miembro del equipo debe crear un tablero llamado:

    VIAJE FIN DE CURSO – Equipo X

    A continuación:

    • Invitad al resto de los miembros del equipo al tablero.
    • Investigad cómo crear las siguientes listas:

    POR HACER → EN PROCESO → EN REVISIÓN → TERMINADO

    !!! Importante !!! Debéis intentar descubrir por vosotros mismos cómo realizar estas operaciones en Trello.

    2.2. Convertir el proyecto en tareas

    Pensad qué habría que hacer para organizar el viaje.

    Debéis crear como mínimo 8 tarjetas.

    No se proporciona la lista de tareas: tenéis que decidir vosotros qué necesita vuestro proyecto.

    Podéis pensar, por ejemplo, en cuestiones relacionadas con:

    • Destino, transporte, alojamiento.
    • Presupuesto, actividades, excursiones.

    !!! Recuerda !!! Una tarjeta debe representar una tarea concreta.
    Una tarjeta llamada Organizar el viaje sería demasiado general.

    2.3. Descubrir Trello

    Investigad cómo conseguir que vuestro tablero cumpla TODOS ESTOS REQUISITOS:

    1. Todos los miembros del equipo deben pertenecer al tablero.
    2. Todas las tarjetas deben tener un responsable.
    3. Al menos 3 tarjetas deben tener una fecha límite.
    4. Una tarjeta debe contener una lista de comprobación (checklist) con al menos 4 elementos.
    5. Debéis crear y utilizar al menos 3 etiquetas.
    6. Una tarjeta debe contener un enlace a una página web relacionada con el viaje.
    7. En una tarjeta, un miembro debe escribir un comentario mencionando a otro compañero.
    8. Al menos una tarea debe pasar de POR HACER a EN PROCESO.
    9. Otra tarea debe llegar hasta TERMINADO.

    !!! Antes de preguntar...!!! Si no sabéis dónde se encuentra alguna opción, intentad descubrirla primero explorando Trello.

    2.4. ¿Qué habéis descubierto?

    Cuando vuestro tablero esté terminado, responded entre todos a las siguientes cuestiones:

    A. ¿Qué diferencia hay entre un tablero, una lista y una tarjeta?

    B. ¿Qué información consideráis imprescindible incluir en una tarjeta para saber exactamente qué hay que hacer?

    C. Si un proyecto durase tres meses, ¿cómo podríamos saber qué está haciendo cada miembro del equipo?

    D. ¿Para qué creéis que sirve la columna EN REVISIÓN?

    E. ¿Qué utilidad podría tener Trello para vuestro Proyecto Intermodular?

    3. Aplicación al Proyecto Intermodular

    El flujo de trabajo que habéis utilizado:

    POR HACER → EN PROCESO → EN REVISIÓN → TERMINADO

    permite visualizar rápidamente el estado de las diferentes tareas de un proyecto.

    A partir de ahora podremos aplicar esta forma de organización al Proyecto Intermodular, utilizando Trello para distribuir tareas, asignar responsables y realizar el seguimiento del trabajo del equipo.
