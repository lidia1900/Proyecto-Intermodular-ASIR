# Documentación del proyecto

La documentación del **Proyecto Intermodular** se realizará utilizando **GitHub**, lo que permitirá mantener organizada y actualizada toda la información del proyecto a medida que avance el curso.

El objetivo será que cada alumno disponga de un repositorio propio en el que irá incorporando la documentación de las distintas fases de su proyecto. Esta documentación se transformará automáticamente en una **página web**, que constituirá la memoria técnica y permitirá consultar fácilmente la evolución y los resultados del trabajo realizado.

Para ello utilizaremos las siguientes tecnologías:

- **GitHub**
- **Markdown**
- **MkDocs**
- **Material for MkDocs**
- **GitHub Actions**
- **GitHub Pages**


## Actividad 1. Preparación del entorno de trabajo y documentación

!!! info "Objetivo de la actividad"

    En esta actividad vas a preparar el **entorno de trabajo que utilizarás durante el desarrollo del Proyecto Intermodular**.

    Este entorno te permitirá **almacenar, organizar, desarrollar y documentar** tu proyecto, manteniendo un registro de los cambios realizados y generando, a partir de la documentación, una **página web que se actualizará a medida que avance el proyecto**.

    Durante la actividad trabajarás con diferentes tecnologías y herramientas:

    - **GitHub**
    - **Markdown**
    - **MkDocs**
    - **GitHub Actions**
    - **GitHub Pages**

    La finalidad de la actividad no es únicamente conseguir que la página web funcione. Lo más importante es que, durante el proceso, **comprendas para qué sirve cada una de estas tecnologías y cómo se relacionan entre sí**.

### Antes de comenzar

Para realizar la actividad necesitarás:

- Disponer de una **cuenta de GitHub**. Si todavía no tienes una, deberás crearla antes de comenzar.
- Disponer de acceso a **ChatGPT**.
- Trabajar desde un navegador web.

No será necesario instalar Git, Python, MkDocs ni ninguna otra herramienta en tu ordenador. Todo el proceso se realizará utilizando la **interfaz web de GitHub**.

### ¿Cómo realizarás la actividad?

Para ayudarte durante el proceso utilizarás **ChatGPT como guía**.

A continuación encontrarás un **prompt preparado específicamente para esta actividad**. Deberás:

1. **Copiar el prompt completo** que aparece a continuación.
2. Abrir **ChatGPT** e iniciar una **nueva conversación**.
3. **Pegar el prompt** y enviarlo.
4. Seguir las instrucciones que ChatGPT te irá proporcionando.
5. Realizar **un paso cada vez** y comprobar que se ha realizado correctamente antes de continuar.
6. Leer las explicaciones que aparecen durante el proceso para comprender **qué estás haciendo, para qué sirve y cómo se relaciona con el resto de tecnologías**.

!!! warning "Importante"

    ChatGPT actuará como **guía durante la actividad**, pero serás tú quien realice las operaciones en GitHub.

    **No avances varios pasos a la vez.** Si encuentras algún problema o el resultado obtenido no coincide con el esperado, indícaselo a ChatGPT y resuelve el problema antes de continuar.

### Resultado de la actividad

Al finalizar deberás disponer de un entorno en GitHub preparado para continuar desarrollando el Proyecto Intermodular y comprender el siguiente flujo de trabajo:

**Documentación → GitHub → MkDocs → GitHub Actions → GitHub Pages → Página web**

A partir de ese momento, utilizarás este entorno para **incorporar y actualizar la documentación de las distintas fases de tu proyecto durante el curso**.
